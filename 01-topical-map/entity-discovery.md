## Key Patterns Learned (Session 3)

### Pattern 6: Google CAPTCHA Persistence
**Problem:** Once Google CAPTCHA triggers from rapid requests, the IP stays blocked for the remainder of the session. Even single-step requests hours later may fail.
**Solution:** DuckDuckGo as permanent fallback. DDG doesn't CAPTCHA and returns clean SERP snippets. For entity discovery specifically, DDG is actually better — it shows direct profile URLs without the AI Overviews/KP clutter Google adds.
**Rule:** For any multi-step search workflow (entity discovery, market data), START with DuckDuckGo. Reserve Google for cases where DDG's index is insufficient.

### Pattern 7: Entity Contamination Is Worse Than Missing Profiles
**Problem:** A missing Zillow profile = Google doesn't have that signal. A wrong LinkedIn brokerage = Google actively has WRONG information.
**Solution:** Contamination cleanup before gap filling. Fix the LinkedIn and HAR duplicates BEFORE creating new profiles.
**Rule:** In entity discovery: contamination > gaps > supplementation. Fix what's wrong before adding what's missing. A wrong brokerage is actively harmful — a missing profile is neutral.
