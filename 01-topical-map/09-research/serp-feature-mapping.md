# Information Foraging & SERP Feature Mapping — Quann.Homes

**Date:** 2026-05-05
**Purpose:** Map the required result character, engagement components, and SERP features for each of Quan's 12 grounded spokes. Every page must be informationally richer than the current top 3 results.

---

## Core Principle

Google determines the "required result character" for each query based on what the top-ranking pages provide AND what SERP features appear. If the top 3 results all feature comparison tables, a page without one is invisible. Your page must not only match the expected format — it must be more findable, more structured, and more complete.

## Information Richness Checklist (Every Page Must Satisfy)

- [ ] Matches the dominant SERP format (table, list, or definition)
- [ ] Contains Texas-specific data (not national averages)
- [ ] Has at least one element NOT found in top 3 competitors
- [ ] Structured with scannable HTML (`<table>`, `<ol>`, `<dl>`, `<h2>`/`<h3>`)
- [ ] First sentence matches search intent (no preamble)
- [ ] Internal links to related spokes and pillar hub
- [ ] CTA to schedule a consultation
