## 6. Content Brief Template

For each node, the copywriter receives a brief with these components (per Koray Seminar Content Item Brief Template, Lecture 84):

### Template Fields
| Component | Description | Source |
|---|---|---|
| **Macro Context** | H1 + title tag text | Processed Topical Map (this document) |
| **Contextual Vector** | Ordered H2-H4 headings with question format | This document (each node's vector section) |
| **Contextual Hierarchy** | Which sections carry more weight, which are supplementary | Article Methodology (below) |
| **Answer Format** | Per-heading: paragraph, table, bullet list, or comparison grid | Designated by predicate family |
| **Answer Terms** | Required vocabulary terms that MUST appear verbatim | Phase 1 Vocabulary Bank (per attribute bucket) |
| **Anchor Texts** | Exact link text for cross-page contextual bridges | Contextual Bridges section |
| **Contextual Borders** | Which sections are core vs. supplementary (macro vs. micro context) | Designated per node |
| **Predicate Family** | Approved verbs for the page | Phase 1 predicate families |
| **Banned Terms** | Words that MUST NOT appear | Phase 1 banned terms list |

### Article Methodology (Per Koray Lectures 21–23)
1. **Open with a scientific definition** — include the central entity and key predicates. Use synonyms and scientific terminology.
2. **State the main benefit** early — supported by evidence (financial, geographic, regulatory).
3. **Use extractive/abstractive summaries** — tables for comparisons, bullets for steps, paragraphs for narrative.
4. **Contextual flow:** Each section's last sentence bridges to the next section's opening.
5. **Contextual connection:** Internal links use ANCHOR TEXT matching target page's H1 — placed at least once BEFORE the actual link to reinforce topical connection.
6. **Every sentence is Entity-First** — the subject leads. No passive voice openers.
