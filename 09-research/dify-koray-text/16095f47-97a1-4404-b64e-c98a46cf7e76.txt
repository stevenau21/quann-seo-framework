The HTML Tag <embed> is used to include an external program or interactive content into an HTML document. The <embed> HTML Tag is part of Programming HTML category in HTML Element Reference. The attributes of the <embed> HTML Tag are height, URL, media type, pixels, global attributes and events attributes.

What is <embed> HTML Tag?
The <embed> HTML Tag is used to embed other programs, often multimedia information such as audio or video, inside an HTML document. It serves as a container for plug-ins such as flash animations. This is a new tag in HTML 5, and it just requires the beginning tag.
How to Use <embed> HTML Tag?
To use the <embed> HTML Tag, the <embed type=”” source=””> tag should be created by the web developer, with the object type put between the type property’s double quotes and the URL of the object specified in the source attribute If required, a width and height property can also be given.
Example Usage of <embed> HTML Tag?
The following example of usage of <embed> HTML tag is given below.
<embed type="video/webm"
src="/media/cc0-videos/tree.mp4"
width="250"
height="200">
What are the Attributes of <embed> HTML Tag?
There are multiple attributes for the <embed> HTML Tag. The following attributes are listed below.
Global Attributes: The <embed> HTML Tag supports Global Attributes. All HTML elements, even those not specified in the standard, can have global attributes. This means that any non-standard elements must nevertheless allow certain characteristics, even if using such elements makes the content non-HTML5 compliant.
Event Attributes: The <embed> HTML Tag supports Event Attributes. The Event Attributes always have a name that begins with “on” and is followed by the name of the event for which it is intended. They specify a script to run when an event of the defined type is dispatched to the element with the specified attributes.
Height Attribute: The <embed> HTML Tag supports Height Attribute. The height of the embedded content is specified by this attribute.
src Attribute: The <embed> HTML Tag supports src Attribute. The address of the external file to embed is specified by this attribute.
Type Attribute:  The <embed> HTML Tag supports Type Attribute. The media type of the embedded material is specified by this attribute.
Width Attribute: The <embed> HTML Tag supports Width Attribute. The width of the embedded content is specified by this attribute.

The other related HTML Tags to the <embed> HTML Tag are listed below.
<script> HTML Tag: The
<script>

<noscript> HTML Tag: The
<noscript>
HTML Tag is related to <embed> HTML Tag because they are both programming tags. The <noscript> HTML Tag specifies an alternative content for people who do not support client-side scripting.
<applet> HTML Tag: The
<applet>
HTML Tag is related to <embed> HTML Tag because they are both programming tags. HTML5 does not support the <applet> HTML Tag. Instead, use <embed> or <object>. This class defines an embedded applet.
<object> HTML Tag: The
<object>
HTML Tag is related to <embed> HTML Tag because they are both programming tags. The HTML Tag <object> specifies an embedded object.
